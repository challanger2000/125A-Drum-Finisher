# User-benefit acceptance plan (Drum Finisher)
- Core must remain transparent at zero settings.
- FINISH must suppress deliberately problematic decay more than the initial attack, across relevant frequencies and real stems; must not darken unproblematic cymbals merely to appear active.
- PUNCH must create measurable level-matched transient contrast on actual drums, not merely add loudness.
- MASS replaces BODY; it must add credible low-mid weight and controlled harmonic density on drums without making cymbals dull. Parameter ID 101 is retained for backward compatibility.
- TIGHT must shorten undesirable low-frequency/tom tails while preserving natural snare sustain.
- GLUE must provide audible cohesion and meaningful compression without cheap pumping, audible cymbal breathing, or unnecessary loudness loss. Measure at 25/50/100% and gain-match before comparing.
- CHARACTER and BYPASS clicks must work inside Studio One, and state/automation must survive reopen/save/restore.
- These are release gates; the new level-matched crest metric is a diagnostic, not a proxy for listening judgement.
- Final needs real stereo drum bus and producer listening A/B, not only automated mono-source fixtures.
